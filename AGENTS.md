# Weight Cut AI

Pinned to **Expo SDK 54** deliberately, not the latest — the dev's installed
Expo Go client only supports SDK 54 (confirmed against the actual device).
Do not bump the `expo` package version without checking that first; going to
SDK 55+ will make the app impossible to preview via Expo Go again.

Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before writing any code.
